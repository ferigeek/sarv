## Contract constraints (do not break in P0)

`GET /feed?user_id=&page=&size=` returns
`{user_id, posts: [{post_id: string, score}], page, size, total}`.
`total` is pre-pagination. Out-of-range page returns `[]`, not an error.
Invalid `page/size` returns `422`. Backend skips non-numeric `post_id`,
drops missing/deleted rows, and falls back to chronological on
empty/exception — keep all of that intact.
